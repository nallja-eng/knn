단계별 조작법

1 · 안개 지도

  1. 미션 버튼(1개, 3개, 5개, 함정 2개)을 고른다.
  2. 별과 가까운 물음표 건물을 미션 수만큼 클릭해 연다. 한 번에 −1.
  3. 다 열면 판정 버튼이 켜진다. A동, B동, 판정 불가 중 하나를 고른다.
  4. '거리 측정기'를 켜면 각 건물까지의 거리가 공짜로 보인다.

미션을 다시 누르면 같은 지도로 새로 시작한다.

2 · 함정 지도

  1. k 버튼(1, 3, 5, 9, 17)을 고른다.
  2. 결과를 보기 전에 동그라미, 세모, 네모, 동점 중 하나를 예측한다.
  3. 노란 점선 원 안의 k개가 투표한 결과와 개수가 나온다.

k=1과 k=17을 꼭 해 보고, 둘 다 이상한 이유를 말해 보자.

3 · 사이즈 감별사

  1. 학생은 1~6번의 거리를 계산해 칸에 쓴다. 거리²나 실제 거리 둘 다 된다.
  2. 선생님 몫(7~12번)은 버튼으로 채운다.
  3. '계산 확인'을 누르면 맞은 칸은 초록, 틀린 칸은 빨강.
  4. k=3, 4, 5의 결과를 S, M, L, 동점 중에서 베팅한다.
  5. '베팅 공개'를 누르면 결과, 가까운 순위, 산점도 연결선이 나온다.

보너스 질문과 함정 카드는 베팅 공개 뒤에 이야기한다.

4 · 고집쟁이 봇 깨기

  1. 동그라미(A) 또는 세모(B) 도구를 고르고 지도 빈 곳을 클릭해 점을 찍는다.
  2. 점 위의 숫자는 별과 가까운 순위(1~5위)다.
  3. 봇(k=1)과 탐정(k=3)의 판정이 달라지면 성공.
  4. 지우개로 점을 하나씩 지우거나, '모두 지우기'로 처음부터.

성공한 뒤에는 k=3과 k=5가 갈리는 지도에 도전한다.

★ · 보스 퀴즈

  1. Q1은 숫자를 쓰고 '확인', Q2와 Q3은 버튼을 고른다.
  2. Q4는 직접 서술한다. 다 쓴 뒤 선생님이 '교사 인정'을 누른다.
  3. 마지막 상자에 학번 또는 별명과 성찰일지를 쓴다.
  4. '결과 저장'을 누르면 모든 단계의 응답이 PDF 한 장으로 내려받아진다. 이 파일을 구글 클래스룸에 제출한다.

온라인 수업에서 진행하는 두 가지 방법

A. 선생님 화면 공유

선생님이 Meet로 화면을 공유하고, 학생은 "3번째 물음표를 열어 주세요"처럼 말로 지시한다. 클릭은 선생님이 대신한다. 학생이 왜 그 건물을 골랐는지 말하게 되어 발문하기 좋다.

B. 학생이 직접 조작

페이지 링크를 학생에게 공유하고 학생이 화면을 공유하며 직접 클릭한다. 코인은 학생 브라우저에만 기록되므로, 끝날 때 최종 코인을 성찰일지에 적게 한다.

교과서 177쪽 표는 루트를 씌우지 않은 값(거리²)으로 순서를 정했다. 루트를 씌우면 순서가 바뀔까?

바뀌지 않는다. 0 이상인 수에서는 큰 수일수록 제곱근도 크기 때문에(√는 증가함수) 대소 관계가 그대로 유지된다. 그래서 순위만 필요할 때는 계산이 간단한 거리²를 써도 된다.

Q4"과제 점수 7점 이상이면 합격"처럼 기준선 하나로 정하는 규칙(임계값 규칙)과 kNN은 판단 방식이 어떻게 다른가? kNN이 더 쓸모 있는 경우를 함께 서술하시오.

임계값 규칙은 사람이 정한 기준선 하나로 판단하므로 한 가지 속성만 반영하고, 데이터가 늘어나도 규칙이 저절로 바뀌지 않는다. kNN은 새 데이터와 기존 데이터 사이의 거리를 계산해 가장 가까운 k개의 결과를 다수결로 따르므로 여러 속성(공부 시간과 과제 점수)을 함께 반영하고, 쌓인 데이터에 따라 판단이 달라진다. 기준선을 정하기 어렵거나 속성이 여러 개일 때 kNN이 더 유용하다. 단, k값과 이상치에 따라 결과가 달라질 수 있다.
